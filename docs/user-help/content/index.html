UWSC#（UWSCSharp）は、UWSCスクリプトを実行するための再実装です。このヘルプでは、UWSC# アプリの基本操作とコマンドライン版の使い方を説明します。

不具合を報告 GitHub Sponsors で支援

このヘルプは、UWSC# アプリ（UWSCSharp.Wpf.exe）とコマンドライン版（UWSCSharp.Cli.exe）の製品バージョン 0.1.0 に対応しています。EXEのプロパティでは、ファイル バージョンは 0.1.0.0 と表示されます。

現在はプレビュー段階です。実装済みの機能にも制限や未確認の条件があります。原版UWSCとの完全互換は確認していません。

使い方を選ぶ

  • 初めて使う：導入と最初の実行
  • マウスやキーボードの操作を記録する
  • スクリプトを書いて実行する
  • スクリプトを予約実行する
  • コマンドラインから実行する

UWSC# アプリとコマンドライン版

種類用途と前提
UWSC# アプリWindows 11 x64向け。画面で読込・編集・保存・基本記録・再生を操作します。ランタイム同梱版には.NETランタイムが含まれます。
コマンドライン版スクリプトと引数を指定して実行します。ソースからの実行には.NET 10 SDKが必要です。

このヘルプの範囲

UWSC# アプリ配布案内と既知の問題に加え、現行実装・機能台帳・テストを照合した言語と関数のリファレンスを掲載しています。原版ヘルプの分類を参考に、実装のある範囲を自作の説明へまとめました。関数の定義、制御文、分野別のスクリプト関数を参照してください。

全引数・全フラグの原版互換を示すものではありません。
