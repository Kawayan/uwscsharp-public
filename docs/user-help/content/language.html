以下は基本構文の例です。全構文・全条件の原版互換を示すものではありません。

式は4,096トークンまでです。名前・値・演算子・括弧・カンマなどをそれぞれ数え、空白は数えません。式の入れ子は128までに制限しています。これらはUWSC#側の制限であり、原版と同じ上限を保証するものではありません。グラフ描画などに使う限定数値式には、別の文字数・要素数・深さの制限があります。

変数・文字列・コメント

// 行末までコメントです
DIM name = "UWSC#"
PRINT "こんにちは、" + name
PRINT 10 + 20

文字列は二重引用符で囲みます。DIMで変数を宣言し、PRINTで値を出力します。

文字列リテラルと連続引用符

末尾の二重引用符が連続する場合、最後の1個を閉じ引用符とし、その前の引用符は文字列に含めます。"""は引用符1個、""""は引用符2個の文字列です。"a""はaと引用符1個になります。一般的な二重引用符エスケープとは個数の数え方が異なります。

PRINT LENGTH(""")
PRINT LENGTH("""")
PRINT "a""
PRINT "a" + "b"

途中へ引用符を入れる場合は"a<#DBL>b"と書けます。"a""b"や、空白を挟んで文字列を並べる書き方は拒否します。文字列の連結には+を使ってください。閉じ引用符がない場合は、実行前に行番号付きのエラーになります。

文字列の連結と比較

+の片方が文字列なら連結します。他方には文字列・EMPTY・有限の数値を使えます。EMPTYは空文字列、数値は環境に依存しない書式になります。通常のTRUE/FALSEは1/0として連結します。NULL・NOTHING・ERROR・配列・HASHTBL・外部オブジェクトは暗黙に文字列化せず、エラーになります。

PRINT "001" + 2
PRINT +"001"
PRINT -"2.5"
PRINT !"0"
TRY
    PRINT "x" + NULL
EXCEPT
    PRINT "error"
ENDTRY

単項の+は値と型を保ちます。-と!は数値変換し、!は0なら1、それ以外なら0です。不正な数値文字列やNULLの数値変換はエラーになります。両方が文字列の比較は通常大小文字を区別せず、OPTION SAMESTRで区別します。カルチャーに依存する照合やUnicode正規化は行いません。数値との混在比較は数値変換を使い、変換できない文字列はエラーになります。

条件と繰返し

DIM count = 3
IFB count > 0
    PRINT "開始"
ELSE
    PRINT "対象なし"
ENDIF

FOR i = 1 TO count
    PRINT i
NEXT

複数行の条件分岐はIFBからENDIF、回数を指定する繰返しはFORからNEXTで記述します。OPTION EXPLICITを指定する場合は、ループ変数も宣言してください。

関数を定義する

PRINT Twice(3)

FUNCTION Twice(value)
    RESULT = value * 2
FEND

関数の戻り値はRESULTへ代入します。この例では関数をメイン処理の後に定義しています。

起動引数と配列

コマンドライン版またはUWSC# アプリへスクリプト名の後に渡す追加引数は、0始まりの配列PARAM_STRで参照できます。要素数はLENGTHで確認します。

IFB LENGTH(PARAM_STR) > 0
    PRINT PARAM_STR[0]
ELSE
    PRINT "引数がありません"
ENDIF

引数がない場合、PARAM_STRは0要素です。存在しない要素へのアクセスはエラーになります。

例：UWSCSharp.Wpf.exe "C:\scripts\sample.uws" "日本語" "a b"。UWSC# アプリは指定したスクリプトを再生し、完了後に終了します。UWSC# アプリを引数なしで起動すると、通常の編集画面を開きます。

空文字列、001、引用符、末尾のバックスラッシュ、<#CR>は、OSから渡された文字列のまま保持します。原版の空引数の省略や特殊文字展開は再現しません。シェルが先に除去した引用符は復元できません。

UWSC# アプリの先頭引数--verify-runtimeは配布検査専用です。スクリプト名の後なら通常の引数になります。起動時の読込み・実行エラーは終了コード1で終了し、UWSC# アプリのエラーダイアログは開きません。標準エラー出力を接続して診断を取得してください。

アプリケーションデータのフォルダー

GET_APPDATA_DIRは、実行開始時にOSから取得するApplicationDataのパスです。名前の大小文字は区別しません。値の取得だけではフォルダーを作成しません。空文字の場合もあります。

PRINT GET_APPDATA_DIR

代入すると、その実行内の関数やCALL先にも変更が伝わります。DIMや仮引数で同名のローカル変数を宣言できますが、PUBLIC/CONSTによる再定義はエラーです。次の実行はOSの値から開始します。ホストがScriptRunOptions.ApplicationDataDirectoryを指定した場合は、空文字を含むその値を使用します。原版との全条件の互換は未確認です。

Windows・本体のフォルダーとスクリプト名

特殊変数実行開始時の値
GET_WIN_DIROSのWindowsフォルダー。通常はC:\Windowsです。
GET_UWSC_DIR実行しているコマンドライン版またはUWSC# アプリの基底フォルダー。スクリプトの配置先やカレントフォルダーとは別です。
GET_UWSC_NAME拡張子を含む主スクリプトのファイル名。CALL先でも主スクリプト名を返し、無名ソースでは空文字になります。
PRINT GET_WIN_DIR
PRINT GET_UWSC_DIR
PRINT GET_UWSC_NAME

名前の大小文字は区別しません。OSとアプリから取得したフォルダーには末尾の区切りを追加しません。アプリの基底フォルダーは末尾の区切りを除きますが、ドライブのルートは保持します。取得だけでフォルダーを作成しません。

ホストがScriptRunOptions.WindowsDirectoryまたはExecutableDirectoryを指定した場合、空文字・空白・相対表記・末尾の区切りもそのまま公開します。代入・DIM・仮引数の扱いはGET_APPDATA_DIRと同じです。PUBLIC/CONSTでの再定義はエラーになり、次の実行では初期値へ戻ります。

コンパイル済みファイルは主スクリプトの情報を保持します。実行時のSourcePathで別の名前を指定しても、その名前へ置き換わりません。コマンドライン版とUWSC# アプリで利用できます。原版との全環境・全操作の互換は未確認です。

システムフォルダー・作業フォルダー・UWSC#の版

特殊変数値
GET_SYS_DIR実行開始時のOSのシステムフォルダー。Windows 11 x64では通常C:\Windows\system32です。
GET_CUR_DIR読取り時の相対ファイル操作の基準フォルダー。コマンドライン版とUWSC# アプリでは主スクリプトのフォルダーで、CALL先でも変わりません。
GET_UWSC_VERUWSC#の実際の版を文字列で返します。0.1.0-preview.1などのprerelease表記を保持し、+以降のビルド情報は除きます。原版の数値5.302とは型も値も異なります。
GET_UWSC_PRO数値0。UWSC#はPro製品ではありません。
PRINT GET_SYS_DIR
PRINT GET_CUR_DIR
PRINT GET_UWSC_VER
PRINT GET_UWSC_PRO

GET_CUR_DIRは読み取り専用で、直接代入はエラーです。他の3変数は実行内で代入でき、次の実行で初期値に戻ります。4変数ともDIMや仮引数で隠蔽できますが、PUBLIC/CONSTによる再定義はエラーです。コマンドライン版とUWSC# アプリで利用できます。

ホストがScriptRunOptions.SystemDirectoryを指定した場合、空文字・空白・相対表記もそのまま公開します。主ファイルへ固定しないファイルadapter、またはadapterがない場合のGET_CUR_DIRは、プロセスの現在の作業フォルダーを毎回取得します。コマンドライン版とUWSC# アプリは実行ごとの基準を固定し、プロセスの作業フォルダーを変更しません。原版のネイティブコードによる変更への追従とは異なります。

OS種別と64bit判定はKINDOFOSを参照してください。

現在のマウス座標と主画面

特殊変数読取り時の値
G_MOUSE_X・G_MOUSE_Yマウスの物理スクリーン座標。呼出し元のDPI認識にかかわらず物理ピクセルで返します。MOUSEORGの原点には影響されず、負の座標も返します。
G_SCREEN_W・G_SCREEN_H主画面の幅と高さ。単位は物理ピクセルで、複数画面を合わせた幅や高さではありません。
G_SCREEN_C主画面の1ピクセル当たりのビット数。たとえば32を返し、色の個数は返しません。
PRINT G_MOUSE_X
PRINT G_MOUSE_Y
PRINT G_SCREEN_W
PRINT G_SCREEN_H
PRINT G_SCREEN_C

値は読取りのたびに取得します。XとYは別々の読取りなので、その間にマウスが動けば異なる時点の値になります。画面情報自体は読み取り専用です。DIMや仮引数で同名のローカル変数を宣言できますが、特殊変数への直接代入とPUBLIC/CONSTでの再定義はエラーです。

コマンドライン版とUWSC# アプリのWindows実行で利用できます。取得失敗はEXCEPTへ通知し、取消や未知のホスト障害は区別します。モニターごとの情報はMONITORで取得できます。

複数行の定数 TEXTBLOCK

TEXTBLOCK message
  コメント記号 // も ; も _ も本文です。
ENDTEXTBLOCK
PRINT message

本文の字下げ・引用符・空行を保持し、改行はCRLFで結びます。終端直前に余分な改行は付けません。空のブロックも可能です。定数として実行開始時に初期化し、再代入と重複定義はエラーです。ENDTEXTBLOCKは単独行または後続コメントの形で指定します。終端がなければ開始物理行で診断します。

通常は<#CR>・<#TAB>・<#DBL>を展開し、OPTION SPECIALCHARがあればそのまま保持します。CALL先とmodule/classの定数にも使えます。

バイト文字列と符号化

通常の文字列を扱うCOPY・POS・LENGTHと、CP932のバイトを扱うCOPYB・POSB・LENGTHBを区別します。NULを含む長さと切出しは保持しますが、POSBの検索はNULで終わり、文字途中のバイトだけは一致しません。

ENCODEは元のバイト列を持つ文字列や型付きバイト配列を返します。表示文字列だけから元の列を作り直しません。配列を復号する場合は対応するCODE_BYTEARRAYまたはCODE_BYTEARRAYWを指定してください。未型付け配列はDECODEへ渡せません。
