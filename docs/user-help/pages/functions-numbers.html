    UWSC# ヘルプ / 数値・数学

    数値・数学

    数値の丸め、べき乗、対数、三角関数などを説明します。

    コマンドライン版とUWSC# アプリで実装のある範囲を説明します。角括弧内は省略可能です。

    INT

    0方向へ小数部を切り捨てます。

    書式

    INT(value)

    引数

    value
    有限数、EMPTY、またはASCII数字・小数点・E/e指数による数値文字列。必須1引数。

    戻り値・結果

    切捨て後の数値。

    対応範囲と注意

    • 有限doubleへ変換してから0方向へ切り捨てます。EMPTYは0。整数型の範囲へは制限しません。
    • 文字列はOSや表示言語に依存しない規則で解析し、前後の空白を受理します。桁区切り・全角数字・D指数・不完全な指数・埋込みNUL・16進表記はエラーです。
    • 引数の過不足・省略は引数式を評価する前にエラーとし、正しい1引数は1回評価します。
    • NULL、NOTHING、配列、連想配列、ERROR、未変換objectや非有限値はエラーです。COM既定memberは暗黙に呼び出しません。
    • COMのVT_BOOLはTRUEを-1として数値化します。通常のTRUEリテラルは1です。
    • 原版の32bit丸め、追加引数、不完全な指数などとは意図した仕様差があります。ゼロ除算は例外となり、TRY/EXCEPTで処理できます。

    例

    PRINT INT(-1.8)

    期待出力：

    -1

    ABS

    絶対値を求めます。

    書式

    ABS(value)

    引数

    value
    有限数、EMPTY、またはASCII数字・小数点・E/e指数による数値文字列。必須1引数。

    戻り値・結果

    符号を取り除いた有限doubleの数値。負の0は正の0になります。

    対応範囲と注意

    • 文字列はOSや表示言語に依存しない規則でdoubleへ変換してから絶対値を求めます。前後の空白を受理し、独自の文字数上限は設けません。
    • EMPTYは0、通常のTRUE/FALSEは1/0です。COM VT_BOOLのTRUE/FALSEも絶対値の結果は1/0です。
    • 引数の過不足・省略は引数式を評価する前にエラーとし、正しい1引数は1回評価します。
    • 非有限値、NULL、NOTHING、ERROR、配列、連想配列、未変換objectはエラーです。COM既定memberは暗黙に呼び出しません。
    • 桁区切り・全角数字・D指数・不完全指数・埋込みNUL・16進文字列はエラーです。16進数リテラルは数値として利用できます。
    • 原版の32bit丸めや追加引数の処理とは意図した仕様差があります。ゼロ除算は例外となり、TRY/EXCEPTで処理できます。

    例

    PRINT ABS(-3)

    期待出力：

    3

    ZCUT

    入力と0の大きい方を返します。

    書式

    ZCUT(value)

    引数

    value
    有限数、EMPTY、またはASCII数字・小数点・E/e指数による数値文字列。必須1引数。

    戻り値・結果

    負の数と負の0なら正の0、正の数なら元の有限double。

    • EMPTYと通常のFALSEは0、通常のTRUEは1です。COM VT_BOOLはTRUE=-1、FALSE=0として数値化するため、ZCUTの結果はどちらも0です。
    • 引数の過不足・省略は引数式を評価する前にエラーとし、正しい1引数は1回評価します。
    • 非有限値、NULL、NOTHING、ERROR、配列、連想配列、未変換objectはエラーです。COM既定memberは暗黙に呼び出しません。
    • 桁区切り・全角数字・D指数・不完全指数・埋込みNUL・16進文字列はエラーです。16進数リテラルは数値として利用できます。
    • 原版の32bit丸めや追加引数の処理とは意図した仕様差があります。ゼロ除算は例外となり、TRY/EXCEPTで処理できます。

    例

    PRINT ZCUT(-3)

    期待出力：

    0

    SQRT

    平方根を求めます。

    書式

    SQRT(value)

    引数

    value
    0以上の有限数、EMPTY、またはASCII数字・小数点・E/e指数の数値文字列。必須1引数。

    戻り値・結果

    非負の有限doubleの平方根。負の0は符号を保持します。

    対応範囲と注意

    • 負数はSQRTの定義域エラーになります。原版がNANを返す場合も、有限double設計により例外としてTRY/EXCEPTで処理します。
    • 文字列はOSや表示言語に依存しない規則で解析します。前後の空白を受理し、独自の文字数上限は設けません。全角・桁区切り・D指数・不完全指数・埋込みNUL・16進文字列はエラーです。
    • EMPTYと通常のFALSEは0、通常のTRUEは1です。COM VT_BOOLはTRUE=-1、FALSE=0として数値化するため、TRUEは定義域エラー、FALSEは0になります。
    • 引数の過不足・省略は引数式を評価する前にエラーとし、正しい1引数は1回評価します。
    • NULL、NOTHING、ERROR、配列、連想配列、未変換object、非有限値はエラーです。COM既定memberは暗黙に呼び出しません。
    • Math.Sqrtを使用し、原版の全精度・FPU/CW・文字列変換を再現するものではありません。ゼロ除算は例外となります。

    例

    PRINT SQRT(9)

    期待出力：

    3

    SIN

    ラジアンで指定した角度の正弦を求めます。

    書式

    SIN(value)

    引数

    value
    ラジアンの有限数、EMPTY、またはASCII数字・小数点・E/e指数の数値文字列。必須1引数。

    戻り値・結果

    -1～1の有限doubleの正弦。負の0は符号を保持します。

    対応範囲と注意

    • EMPTYは0、通常TRUE/FALSEは1/0、COM VT_BOOLは-1/0として扱います。
    • 文字列は前後の空白とE/e指数を受理し、独自の文字数上限を設けません。16進文字列・全角・桁区切り・D指数・不完全指数・NUL・非有限値は拒否します。
    • NULL・NOTHING・ERROR・配列・連想配列・未変換objectは拒否し、COM既定memberを暗黙に呼び出しません。
    • 引数の過不足・省略は式評価前にエラーにし、正しい1引数は1回評価します。原版のx87精度・FPU/CW・全localeを再現するものではありません。

    例

    PRINT SIN(0)

    期待出力：

    0

    LN

    自然対数を求めます。

    書式

    LN(value)

    引数

    value
    0より大きい有限数、または同じ範囲の値へ変換できるASCII数字・小数点・E/e指数の数値文字列。必須1引数。

    戻り値・結果

    有限doubleの自然対数。1からは正の0、0より大きく1未満の入力からは負の結果、1より大きい入力からは正の結果を返します。

    対応範囲と注意

    • Math.Logで計算します。0以下はLNの定義域エラーになります。原版の-INF/NANを返す動作は採用していません。
    • 最小の正の非正規化数から最大有限値までを扱い、1の近傍を任意に1へ丸めません。文字列の数値変換で0へ丸められた入力も拒否します。
    • EMPTYは0なので定義域外です。通常TRUEは1なので結果は0、FALSEは定義域外です。COM VT_BOOLは-1/0なのでTRUE/FALSEとも定義域外になります。
    • 文字列は前後の空白とE/e指数を受理し、独自の文字数上限を設けません。16進文字列・全角・桁区切り・D指数・不完全指数・NUL・非有限値は拒否します。
    • NULL・NOTHING・ERROR・配列・連想配列・未変換objectは拒否し、COM既定memberを暗黙に呼び出しません。
    • 引数の過不足・省略は式評価前にエラーにし、正しい1引数は1回評価します。原版のx87精度・FPU/CW・全localeを再現するものではありません。

    例

    PRINT LN(1)

    期待出力：

    0

    ARCSIN

    逆正弦を求めます。

    書式

    ARCSIN(value)

    引数

    value
    -1以上1以下の有限数、EMPTY、または同じ範囲の値へ変換できる数値文字列。必須1引数。

    戻り値・結果

    -π/2～π/2のラジアン角度を有限doubleで返します。正負の0の符号を保持します。

    • 文字列はInvariantCultureとNumberStyles.Floatで変換します。前後の空白とE/e指数を受理し、独自の文字数上限を設けません。16進文字列・全角・桁区切り・D指数・不完全指数・NUL・非有限値は拒否します。
    • NULL・NOTHING・ERROR・配列・連想配列・未変換objectは拒否し、COM既定memberを暗黙に呼び出しません。
    • 個数の過不足・省略は式評価前にエラーにし、正しい1引数は1回評価します。原版のx87精度・FPU/CW・全locale・NANを再現するものではありません。

    0

    SET8087CW

    現在の実行主体で使うx87浮動小数点制御語を指定します。

    書式

    SET8087CW([controlWord])

    引数

    controlWord
    0～65535の制御語。有限数、TRUE・FALSE、数値文字列を受け取り、小数部分を0方向へ切り捨ててから範囲を検査します。0、省略、EMPTYは通常の数値演算に戻します。

    戻り値・結果

    空文字列。

    対応範囲と注意

    • 非ゼロの指定には、Windows x64向けにビルドしたコマンドライン版またはUWSC# アプリに付属する浮動小数点DLLが必要です。DLLを読み込めない場合はエラーになります。
    • UWSC# アプリでは編集画面からの再生、引数・関連付け起動、予約実行で使用できます。
    • 制御語は式の加減乗除、FORの加算、SQRT・SIN・COS・TAN・EXP・LN・ARCTAN・INT・ABS・LOGN・ARCSIN・ARCCOS・CEIL・ZCUT・POWERの演算に適用されます。引数と結果は有限値に限り、ゼロ除算はエラーです。例外をマスクしていても、演算結果が有限範囲を超えるとエラーになります。
    • VARTYPEはWindowsのVariant変換を使い、MODは.NETのdouble剰余を使います。どちらも指定したx87制御語から独立しています。
    • 制御語の変更や0による復元は、呼出し元と、その後に開始するTHREADに反映されます。既に動いている別のTHREADは自身の設定を使い続けます。
    • CALL先は呼出し元の設定を引き継ぎ、そこで変更した設定は呼出し元へ戻った後も有効です。
    • 一時停止から再開した実行は設定を引き継ぎます。新しく始めた独立した実行では通常の数値演算が有効です。
    • 原版Free 5.3.0.2ではEMPTYはエラーで、NOTHINGを渡すと復元します。UWSC#ではEMPTYで復元し、NOTHINGはエラーです。原版は余分な引数も評価します。UWSC#で引数を2個以上渡すと、評価前にエラーになります。

    例

    SET8087CW(0)
PRINT SQRT(4)

    期待出力：

    2

    ROUND

    指定する桁で数値を丸めます。

    書式

    ROUND(value, [digits])

    引数

    value
    有限数、EMPTY、またはASCII数字・小数点・E/e指数の数値文字列。必須。
    digits
    既定0。省略位置とEMPTYも0。数値化して0方向へ切り捨てた後の許容範囲は-20～20。負数は小数側、正数は整数側の桁を指定します。20.9は20として受理します。

    戻り値・結果

    指定桁で丸めた数値。

    対応範囲と注意

    • 既存の.NET doubleによる偶数丸めを採用しています。ROUND(2.675,-2)とROUND(2.685,-2)はどちらも2.68です。原版の80bit計算とは意図した差があり、十進数の理想計算と常に一致するものでもありません。
    • 指定単位がdoubleの刻みより細かい場合は入力をそのまま返します。巨大な有限値を不要に拡大してエラーにしません。符号付き0とunderflowの0を受理します。
    • 両引数の文字列変換はOSや表示言語に依存しません。全角・桁区切り・D指数・不完全指数・埋込みNUL・16進文字列はエラーです。
    • EMPTYは0、通常のTRUE/FALSEは1/0、COM VT_BOOLは-1/0として数値化します。NULL、NOTHING、ERROR、配列、連想配列、未変換object、非有限値はエラーです。COM既定memberは暗黙に呼び出しません。
    • 個数の過不足・第1引数の省略は式評価前にエラーになります。正しい個数では全引数式を左から1回ずつ評価してから変換するため、値の変換エラーがあっても後続式の副作用は発生し得ます。
    • 桁数の符号を小数桁数指定と取り違えないでください。ゼロ除算は例外となり、TRY/EXCEPTで処理できます。

    例

    PRINT ROUND(2.5)
PRINT ROUND(1234, 2)

    期待出力：

    2
1200

    CEIL

    数値以上で最小の整数値へ切り上げます。

    書式

    CEIL(value)

    引数

    value
    有限数、EMPTY、通常Boolean、または採用文法の数値文字列。必須1引数。

    戻り値・結果

    有限doubleの切上げ結果。整数値はそのまま返します。

    対応範囲と注意

    • Math.Ceilingを使い、Int32/Int64への変換や32bit折返しは行いません。CEIL(2147483647.1)は2147483648です。原版や旧実装の折返しとは意図的に異なります。
    • 文字列はInvariantCulture/NumberStyles.Floatで有限doubleへ変換してから切り上げます。E/e指数と前後の空白を受理し、16進文字列・桁区切り・全角・D指数・不完全指数・NUL・非有限値を拒否します。
    • EMPTY=0、通常TRUE/FALSE=1/0、COM VT_BOOL=-1/0です。NULL・NOTHING・配列・連想配列・ERROR・未変換objectは拒否し、COM既定memberを暗黙に呼びません。
    • 過不足と省略は式評価前に拒否し、正しい1引数は1回評価します。正負の0を保持し、CEIL(-0.1)は-0になります。
    • 全有限doubleを受理します。十進文字列の厳密値、全localeやx87中間精度の原版完全再現は採用しません。

    例

    PRINT CEIL(1.2)
PRINT CEIL(-1.2)

    期待出力：

    2
-1

    POWER

    べき乗を計算します。

    書式

    POWER(base, exponent)

    引数

    base
    底。有限数、EMPTY、または採用文法の数値文字列。必須。
    exponent
    指数。有限数、EMPTY、または採用文法の数値文字列。必須。負の底には整数を指定します。

    戻り値・結果

    べき乗の数値。

    対応範囲と注意

    • Math.Powで計算します。0の負の累乗と、負の底に非整数指数を指定する計算は定義域エラーです。POWER(0,0)は1です。
    • 旧実装の「一部の指数では底0から0を返す」互換処理は廃止しました。POWER(0,-0.5)やPOWER(0,-2147483648)も例外になります。
    • POWER(-0,0.5)は正の0、POWER(-0,3)は負の0です。非有限結果はエラーにし、underflowの正負の0は受理します。指数もdoubleなので巨大整数を任意精度で区別するものではありません。
    • 両引数の文字列はOSの表示言語に依存しない規則で解析し、指数表記はE/eです。全角・桁区切り・D指数・不完全指数・NUL・16進文字列は拒否します。EMPTYは0、通常TRUE/FALSEは1/0、COM VT_BOOLは-1/0です。
    • 両引数が必須です。個数の過不足と省略は式評価前に拒否します。正しい2引数では全式を左から1回ずつ評価してから変換するため、変換不能な底の後続式も評価されます。
    • NULL、NOTHING、ERROR、配列、連想配列、未変換object、非有限入力は拒否します。COM既定memberは暗黙に呼び出しません。原版のNAN/INF・x87中間精度・32bitの指数経路・追加引数とは意図した差があります。

    例

    PRINT POWER(2, 3)

    期待出力：

    8

    LOGN

    底を指定して対数を求めます。

    書式

    LOGN(base, value)

    引数

    base
    0より大きく1以外の有限数、または同じ範囲へ変換できる数値文字列。必須。
    value
    0より大きい有限数、または同じ範囲へ変換できる数値文字列。必須。

    戻り値・結果

    指定した底の有限doubleの対数。真数1では、底が1より大きい場合は正の0、1未満の場合は負の0を返します。

    対応範囲と注意

    • Math.Log(value, base)で計算します。底0・底1・負の底と、0以下の真数はLOGNの定義域エラーになります。真数1でも底0は拒否します。
    • 0より大きく1未満の底と、1に隣接する正のdoubleも扱います。最小の正の非正規化数から最大有限値までを入力として扱い、1付近を任意に1へ丸めません。
    • EMPTYは0なので両位置で定義域外です。通常TRUEは真数1として使えますが、底1は定義域外です。FALSEとCOM VT_BOOLのTRUE/FALSEは両位置で定義域外です。
    • 両引数の文字列はInvariantCultureとNumberStyles.Floatで変換します。前後の空白とE/e指数を受理し、独自の文字数上限を設けません。16進文字列・全角・桁区切り・D指数・不完全指数・NUL・非有限値は拒否します。
    • NULL・NOTHING・ERROR・配列・連想配列・未変換objectは拒否し、COM既定memberを暗黙に呼び出しません。
    • 個数の過不足・省略は式評価前にエラーにします。正しい2引数は左から1回ずつ式を評価し、全式の評価後に底・真数の順で変換、底・真数の順で定義域検査を行います。
    • 原版のx87精度・FPU/CW・全locale・INF/NAN・底0の特例を再現するものではありません。

    例

    PRINT LOGN(10, 100)

    期待出力：

    2

    RANDOM

    上限未満の擬似乱数を返し、共有する乱数状態を1段進めます。

    書式

    RANDOM([range])

    引数

    range
    省略時は0以上1未満の小数。指定時は有限数へ変換し、0方向へ切り捨てたInt32を上限として使います。

    戻り値・結果

    正のrangeでは0以上range未満の整数。range=0は0。省略時は小数。結果の型は数値です。

    対応範囲と注意

    • 0でも状態を1段消費します。不正な変換や取消ではこの呼出しの状態を進めません。余分な引数は評価前に拒否します。有効な1引数は1回評価し、評価済みOmitted値は省略として扱います。
    • 文字列はInvariantCulture/NumberStyles.Floatで変換します。E/e指数と前後の空白を受理し、16進文字列・桁区切り・全角・D指数・不完全指数・NUL・非有限値は拒否します。切捨て後にInt32範囲を検査します。
    • EMPTY=0、通常TRUE/FALSE=1/0、COM VT_BOOL=-1/0です。NULL・NOTHING・配列・連想配列・ERROR・未変換objectは拒否します。COM既定memberを暗黙に呼びません。
    • 負のrangeも既存互換のため受理します。unsignedへ読み替えた上限と状態の積の上位32bitをsigned整数として返すため、通常の0以上range未満という範囲にはなりません。負値を拒否する案はRANDOM-COMPLETION.mdに記録しています。
    • 既定はプロセス内共有の32bit LCGで、状態更新はlockで保護します。初期seedはEnvironment.TickCount、ホストは明示seedのUwscRandomを注入できます。並行時の呼出し順序や原版の初期seed・全localeの再現、暗号用途の品質は保証しません。
