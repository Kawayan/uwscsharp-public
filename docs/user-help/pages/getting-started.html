    UWSC# ヘルプ / 導入と最初の実行

    導入と最初の実行

    最初は、画面への入力を送らないPRINTの例で実行結果を確認します。

    UWSC# アプリ配布版を使う

    1. GitHub ReleasesからWindows x64向けのZIPを取得し、書込み可能なフォルダーへすべて展開します。
    2. UWSCSharp.Wpf.exeを起動します。ランタイム同梱版では.NETの事前インストールは不要です。初回は通常%TEMP%/.netへ同梱ライブラリが展開されます。
    3. 「読込」で同梱のexamples/hello.uwsを開き、「再生」を押します。
    4. 「スクリプト編集・実行結果」を展開し、PRINTの出力を確認します。

    配布版番号と発行元コミットは同梱のrelease.jsonで確認できます。ライセンス表示と案内も保管してください。

    32ビットDLLを呼び出す

    ランタイム同梱版でも、DEF_DLLで32ビットDLLを呼び出す場合はx86版の.NET 10 Runtimeが必要です。

    1. Microsoftの.NET 10ダウンロードページを開きます。
    2. 「.NET Runtime」のWindows用インストーラーで「x86」を選び、インストールします。
    3. インストールが終わったら、DLLを呼び出すスクリプトを再実行します。

    自分で書いて試す

    次の内容を編集欄へ入力し、「再生」を押してください。

    PRINT "こんにちは、UWSC#"
PRINT 1 + 2

    実行結果に挨拶と数値の3が表示されます。保存するときはhello.uwsなどの名前を指定します。

    .uwsを関連付ける（検証中）

    配布版の「関連付け」で「候補を登録」を選ぶと、現在の配置をWindowsの候補に登録します。既定アプリの選択はWindowsの設定で行います。登録だけでは既定アプリは変わりません。

    解除は同じ配置の画面で「登録を解除」を選びます。ZIPを移動する前に解除し、移動後に登録し直してください。別の配置の登録や変更された登録がある場合は、操作を中止して理由を表示します。

    MSIのセットアップでは「.uwsの関連付け候補を登録」を選べます。初期状態では選択されず、選んでも既定アプリは変わりません。MSIのオプションで登録した候補は、変更されていなければ選択解除またはアンインストール時に解除します。画面から登録した場合や解除後に登録し直した場合は、MSIを削除する前に同じ配置の画面で解除してください。

    関連付けで開いたスクリプトは、スクリプトがあるフォルダーを基準に相対パスを解決します。正常終了後は画面を閉じ、失敗時は画面を残します。Windows シェルからファイルを開く経路は検証済みです。Windows の設定で既定アプリを選択する操作、Explorer 画面からの起動、MSI 画面の操作、原版との比較は未確認です。

    ソースから起動する

    Windowsで.NET 10 SDKを用意し、リポジトリのルートで実行します。SDKの基準はglobal.jsonの10.0.301です。

    dotnet run --project src/UWSCSharp.Wpf
dotnet run --project src/UWSCSharp.Cli -- distribution/wpf-preview/examples/hello.uws

    UWSC# アプリでの編集と保存は読込・編集・保存、引数の指定はコマンドライン版の使い方と起動引数を参照してください。
