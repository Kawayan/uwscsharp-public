    UWSC# ヘルプ / 文字列

    文字列

    文字位置、切出し、検索、変換の書式と境界を説明します。

    コマンドライン版とUWSC# アプリで実装のある範囲を説明します。角括弧内は省略可能です。

    COPY

    文字列の一部を切り出します。

    書式

    COPY(text, start, [count])

    引数

    text
    元の文字列。
    start
    1始まりの位置。1未満は先頭として扱います。
    count
    切り出す論理文字数。省略時は末尾まで。負数は空文字列。

    戻り値・結果

    切り出した文字列。範囲を超えた開始位置では空文字列。

    対応範囲と注意

    • 開始位置は1起点で、1以下は先頭、末尾を超えると空文字列になります。有限数は0方向へ切り捨て、非常に大きな位置・長さも文字列境界へ収めます。
    • count未指定・省略・EMPTYは末尾まで、負数または0は空文字列です。startのEMPTYは0として扱います。必須引数の省略は式評価前に拒否します。
    • 有効なサロゲートペアは1文字、孤立したUTF-16単位も各1文字として保存します。NULを保持し、結合文字は別々に数えます。不正UTF-16の数え方は従来のLENGTH/POSと異なります。
    • 位置・長さの文字列は共通の有限double文法です。前後空白・E/e指数を受理し、16進文字列・NUL・桁区切り・不完全指数・非有限値を拒否します。
    • 数値textはInvariantCultureで文字列化します。通常Booleanは1/0、COM VT_BOOLは-1/0です。NULL・NOTHING・ERROR・配列・連想配列・未変換objectは型エラーです。
    • OPTION SAMESTRによる変化はありません。原版の不正UTF-16や全Variant変換の再現は行いません。

    例

    PRINT COPY("ABCDE", 2, 3)

    期待出力：

    BCD

    LENGTH

    文字列の論理長、配列の第1次元の長さ、ハッシュのキー件数などを返します。

    書式

    LENGTH(value)

    引数

    value
    文字列・配列・HASHTBL・対応するCOMコレクション。

    戻り値・結果

    文字数または件数。

    対応範囲と注意

    • 有効なサロゲートペアを1文字、それ以外の各UTF-16単位を1文字と数えます。NULと孤立単位も数え、結合文字は独立した文字です。COPYと同じ文字単位です。
    • 配列は先頭次元の要素数です。多次元の積や入れ子の総和ではありません。HASHTBLはキー数を返します。
    • 数値はInvariantCultureのG書式で文字列化して数えます。通常Booleanは1/0なので各1文字、COM VT_BOOLのTRUEは-1で2文字です。EMPTYは0、NULL・NOTHING・ERROR・非有限値は型/有限値エラーです。
    • 通常InterpreterのCOM objectはadapterによる列挙件数を返します。Count propertyを読まず、ALL_OLE_ITEMを変更しません。COM列挙のhost障害は実行元へ伝えます。
    • 必須1/最大1引数で、個数・省略を式評価前に検査します。OPTION SAMESTRの影響はありません。
    • 原版のBoolean表記・不正UTF-16・全Variant変換は再現しません。
    • 採用したCOM生成・取得・名前解決・呼出し・列挙のHRESULT失敗はTRY/EXCEPTで処理できます。メモリ不足・解放失敗・未知のadapter障害まで捕捉するものではありません。
    • 1要素のScripting.Dictionaryは原版との比較で8、現実装では列挙件数1でした。原版の全COM値の規則を再現する仕様ではありません。
    • COMへ渡せない値、表現できない返値、不正な列挙応答の採用した検証エラーもTRY/EXCEPTで処理できます。内部障害を含む変換失敗を一律に捕捉する仕様ではありません。
    • 列挙できないCOM objectはエラーです。WScript.Shellでは原版が8を返す条件でも、現実装はTRY/EXCEPTで処理できるエラーとします。
    • SAFEARRAYで作成した型付き配列も第1次元の長さを返します。原版で型付き配列のLENGTHがエラーになる条件との差は、採用した仕様です。

    例

    PRINT LENGTH("ABC")

    期待出力：

    3

    LENGTHS

    文字列全体のUTF-16コード単位数を返します。

    書式

    LENGTHS(text)

    引数

    text
    対象文字列。

    戻り値・結果

    UTF-16単位数。空文字列・EMPTYは0。

    対応範囲と注意

    • 必須1引数です。引数の省略・過不足は評価前に拒否します。
    • 有効なサロゲートペアは2、孤立単位は1として数えます。NULの後も含み、正規化しません。表示幅や書記素数、バイト数とは異なります。
    • LENGTHは有効ペアを1として数えます。配列・連想配列の件数にはLENGTHを使い、LENGTHSはそれらを拒否します。
    • 有限数値は文化設定に依存せず文字列化します。通常TRUE/FALSEの長さは1/1、COM Booleanは-1/0なので2/1です。負の0は-0の2、1e20は1E+20の5です。
    • 文字列は数値へ解析しません。文字列NaNは3、Infinityは8です。非有限Number、NULL・NOTHING・ERROR・配列・連想配列・objectは型エラーです。
    • OPTION SAMESTRと文化設定には依存しません。原版の全Unicode・locale・Variant条件と数値表示の一致は未確認です。

    例

    PRINT LENGTHS("ABC")

    期待出力：

    3

    POS

    指定文字列が現れる位置を探します。

    書式

    POS(needle, text, [occurrence])

    引数

    needle
    検索する文字列。
    text
    検索対象。
    occurrence
    既定1。正数は先頭から、負数は末尾から数えます。0は1へ補正。

    戻り値・結果

    見つかった位置を1始まりの論理文字位置で返します。見つからなければ0。

    対応範囲と注意

    • 重なりを含むn個目を検索します。正数は先頭から、負数は末尾からです。回数の既定・省略・EMPTY・0は1です。
    • 回数は有限数へ変換して0方向へ切り捨て、可能な一致数を超える場合は0を返します。前後空白・E/e指数の数値文字列を使えますが、16進文字列・不完全指数・NUL・非有限値は拒否します。
    • 有効サロゲートペアの途中で始まる・終わる一致を除きます。孤立単位とNULは検索でき、戻り位置はCOPY・LENGTHと同じ文字単位の1起点です。空needle/sourceと不一致は0です。
    • 既定はOrdinalIgnoreCase、OPTION SAMESTRではOrdinalです。culture依存の比較やUnicode正規化は追加しません。原版と異なる大小文字の一致があります。
    • 数値のneedle/sourceはInvariantCulture G書式で文字列化します。通常Booleanは1/0、COM VT_BOOLは-1/0です。EMPTYは空文字列、NULL・NOTHING・ERROR・配列・連想配列・未変換objectは型エラーです。
    • 必須2/最大3引数。個数・必須省略は式評価前に拒否し、有効な引数は左から右へ各1回評価します。空needle/sourceでも不正な回数は拒否します。

    例

    PRINT POS("B", "ABC")

    期待出力：

    2

    BETWEENSTR

    前後の区切り文字の間にある文字列を取得します。

    書式

    BETWEENSTR(text, [before, after, occurrence, fromStart])

    引数

    text
    検索対象。
    before, after
    前後の区切り。省略時は空文字列。
    occurrence
    既定1、負数で逆方向、0は1として扱います。
    fromStart
    既定FALSE。次の候補の探索を、TRUEなら前区切りの終端から、FALSEなら後区切りの終端から続けます。

    戻り値・結果

    一致した区間の文字列。該当がなければEMPTY。

    対応範囲と注意

    • 必須1/最大5引数。過不足と必須位置の省略は評価前に拒否します。任意位置の省略は既定値を使います。
    • 前後の空文字/EMPTYは先頭・末尾を表します。空の内容が見つかれば空String、未検出や回数不足はEMPTYを返します。
    • 回数は有限数値へ変換し、0方向へ切り捨てます。0は1へ補正し、負は後ろから検索します。EMPTYも0です。巨大な有限回数は不成立になります。
    • 数え方フラグも有限変換し、切捨て後の非0で真を判定します。真は検索方向内の前区切り後、偽は後区切り後から次を数えます。回数・フラグの16進文字列や非有限値は拒否します。
    • textと区切りは共通の有限文字列化を使い、COM Booleanは-1/0です。非有限Number、NULL・NOTHING・ERROR・配列・連想配列・object等は型エラーです。
    • 両方向とも既定はOrdinalIgnoreCase、OPTION SAMESTRではOrdinalです。有効ペア内部では区切らず、孤立単位とNUL後続は保持します。正規化せず、元の表記と順序を返します。
    • 文字列リテラルの解析にはOPTION SPECIALCHARが適用されます。関数内で実行時の<#TAB>等を再変換せず、内部markerも挿入しません。
    • 原版の全Unicode・locale・Variant条件とmarker処理の一致は未確認です。

    例

    PRINT BETWEENSTR("a[b]c", "[", "]")

    期待出力：

    b

    REPLACE

    文字列中の一致箇所を別の文字列へ置換します。

    書式

    REPLACE(text, from, to)

    引数

    text
    元の文字列。
    from
    検索文字列。
    to
    置換後の文字列。

    戻り値・結果

    置換後の文字列。

    対応範囲と注意

    • 元の文字列を左から非重複で置換し、挿入文字列を再検索しません。空fromは変更せず、空toは一致部分を削除します。正規表現ではありません。
    • 有効サロゲートペアの途中で始まる・終わる一致を除き、孤立単位とNULは扱います。明示したtoの孤立単位も保存し、正規化は行いません。
    • 既定はOrdinalIgnoreCase、OPTION SAMESTRではOrdinalです。原版と異なる大小文字の一致があります。
    • 数値はInvariantCulture G書式で文字列化します。通常Booleanは1/0、COM VT_BOOLは-1/0です。EMPTYは空文字列、NULL・NOTHING・ERROR・配列・連想配列・未変換object・非有限Numberは型/有限値エラーです。
    • 必須3/最大3引数で、省略と個数を式評価前に検査します。空fromや不一致でも指定した全引数の型変換は検査します。
    • 出力長を先に計算しInt32を超える場合は確保前にエラーとします。100万文字の独自上限はありませんが、CLR上限・空きメモリにより確保に失敗する場合があります。CHGMOJとREPLACEは同じ実装です。

    例

    PRINT REPLACE("a-b", "-", "/")

    期待出力：

    a/b

    引数

    対応範囲と注意

    • 元の文字列を左から非重複で置換し、挿入文字列を再検索しません。空fromは変更せず、空toは一致部分を削除します。正規表現ではありません。
    • 有効サロゲートペアの途中で始まる・終わる一致を除き、孤立単位とNULは扱います。明示したtoの孤立単位も保存し、正規化は行いません。
    • 既定はOrdinalIgnoreCase、OPTION SAMESTRではOrdinalです。原版と異なる大小文字の一致があります。
    • 数値はInvariantCulture G書式で文字列化します。通常Booleanは1/0、COM VT_BOOLは-1/0です。EMPTYは空文字列、NULL・NOTHING・ERROR・配列・連想配列・未変換object・非有限Numberは型/有限値エラーです。
    • 必須3/最大3引数で、省略と個数を式評価前に検査します。空fromや不一致でも指定した全引数の型変換は検査します。

    PRINT CHGMOJ("a-b", "-", "/")

    a/b

    TRIM

    両端の空白・制御文字を取り除きます。

    書式

    TRIM(text, [fullWidth])

    引数

    text
    元の文字列。
    fullWidth
    既定FALSE。TRUEで全角空白U+3000も除去します。

    戻り値・結果

    両端を取り除いた文字列。

    対応範囲と注意

    • 両端のU+0000〜U+0020だけを除去し、内部の対象文字は残します。DEL・NEL・NBSPなど、Unicodeの空白すべてを除く機能ではありません。
    • 通常版の全角指定が有効な場合はU+3000も除去します。指定は有限数へ変換し、0方向へ切り捨てた結果が非0なら有効です。0.5/-0.5は無効、1.5や大きな有限値は有効です。
    • 全角指定の既定・省略・EMPTYは無効です。数値文字列は前後空白・E/e指数を受理し、16進表記・不完全指数・NUL・桁区切り・非有限値を拒否します。
    • textの数値はInvariantCulture G書式で文字列化します。通常Booleanは1/0、COM VT_BOOLは-1/0。EMPTYは空文字列、NULL・NOTHING・ERROR・配列・連想配列・未変換objectは型エラーです。
    • 必須1/最大2引数。個数と必須省略は式評価前に拒否し、有効な引数は左から右へ各1回評価します。空textでも全角指定の変換は検査します。
    • 孤立単位・補助平面・結合文字を正規化せず保持します。OPTION SAMESTRの影響はありません。

    例

    PRINT TRIM("  sample  ")

    期待出力：

    sample

    CHKNUM

    文字列が共通文法の有限doubleへ変換できるかを調べます。

    書式

    CHKNUM(text)

    引数

    text
    判定する文字列。Numberは表示文字列を判定し、EMPTYは空文字列として扱います。必須1引数。

    戻り値・結果

    有限doubleへ変換できれば1、変換できない文字列は0。表示できない型はエラーです。

    対応範囲と注意

    • InvariantCulture/NumberStyles.Floatで判定します。ASCIIの符号・小数・E/e指数・前後空白を受理し、指数の符号は任意です。独自の文字数上限は設けません。
    • 16進文字列・全角・桁区切り・D指数・不完全指数・NUL・NaN/Infinity/overflowは0です。underflowで0へ丸められる文字列は1です。数値リテラル$FFは既にNumberなので1です。
    • 通常/COM Booleanは数値表示として判定するため、TRUE/FALSEのどちらも1になります。EMPTYは0、NULL・NOTHING・ERROR・配列・連想配列・未変換objectは型エラーです。COM既定memberを暗黙に呼びません。
    • 過不足・省略は式評価前に拒否し、有効な引数は1回評価します。個数・型のエラーはTRY/EXCEPTで捕捉できます。
    • 原版・旧実装から文法を変更しました。CHKNUM("1e3")とCHKNUM(" 12.5 ")は1、CHKNUM("$FF")は0です。VALも同じ文字列文法を共有しています。厳密な十進精度や整数精度を保証する判定でもありません。
    • 戻り値は数値として1/0を保持する論理型です。VARTYPEで照会すると11、整数へ明示変換しても1/0になります。

    例

    PRINT CHKNUM("123")
PRINT CHKNUM("abc")

    期待出力：

    1
0

    VAL

    数値文字列を数値へ変換します。

    書式

    VAL(text, [errorValue])

    引数

    text
    変換する文字列または数値。必須。EMPTYは空文字列として変換失敗になります。
    errorValue
    変換失敗時の有限数。省略/Omittedは-999999。使用時に共通数値変換を行い、EMPTYは0です。

    戻り値・結果

    共通文法で変換した有限Number、または数値化したerrorValue。

    対応範囲と注意

    • CHKNUMと同じInvariantCulture/NumberStyles.Floatの文字列文法です。E/e指数と前後空白を受理し、独自の文字数上限は設けません。16進文字列・全角・桁区切り・D指数・不完全指数・NUL・非有限値は変換失敗としてerrorValueを返します。
    • 有限Numberは直接扱い、数値リテラル$FFは255です。通常TRUE/FALSEは1/0、保持済みCOM VT_BOOLは-1/0になります。underflowした0や負の0も変換成功とし、doubleの精度を超える厳密演算は行いません。
    • NULL・NOTHING・ERROR・配列・連想配列・未変換objectは入力の型エラーです。COM既定memberを暗黙に呼びません。使用するerrorValueも有限数へ変換できなければエラーです。
    • 必須1/最大2引数を評価前に検査し、正常な引数は左から右へ各1回評価します。入力が成功すればerrorValueの数値化は省略しますが、式の評価は省略しません。VAL("1","bad")は1、VAL("1",1/0)はゼロ除算例外です。
    • 旧実装・原版からの意図した変更です。VAL("$FFFFFFFF")は既定の-999999、数値リテラル$FFFFFFFFは4294967295です。既定エラー値はERR_VALUEと同じ数値であり、原版の任意型fallbackや全localeの再現は採用しません。

    例

    PRINT VAL("001")
PRINT VAL("abc", 0)

    期待出力：

    1
0

    FORMAT

    数値の表示形式を整えるか、文字列を指定幅まで反復します。

    書式

    FORMAT(value, width, [digits])

    引数

    value
    数値、または反復パターンとして扱う文字列。数値の文字列もパターンになります。
    width
    0〜1,000,000。数値では最小幅、文字列ではUTF-16単位の反復幅。
    digits
    小数桁数。既定0、-1は切捨て後の符号付きInt64の16進表示。範囲-1〜20。

    戻り値・結果

    整形後の文字列。

    対応範囲と注意

    • 必須2/最大3引数。個数と必須引数の省略は式評価前に検査します。digitsの省略は0です。
    • 数値はInvariantCultureの固定小数点書式を使い、短い場合は左を空白で埋めます。幅を超えても切り詰めず、負の0の符号を保持します。
    • digits=-1では大文字16進を返し、負数は64ビットの2の補数で16桁になります。Int64範囲外はエラーです。doubleの丸めによりInt64.MaxValue相当の入力も上限外になります。
    • 幅・桁数は有限数へ変換して0方向へ切り捨てます。前後空白・E/e指数の数値文字列は使えますが、16進文字列・NUL・非有限値は拒否します。通常Booleanは1/0、COM VT_BOOLは-1/0です。
    • 文字列はUTF-16単位で反復し、空文字列は空文字列を返します。サロゲートを途中で切ることがあります。文字列でも指定したdigitsの範囲を検査します。
    • EMPTYの数値入力は0。NULL・NOTHING・ERROR・配列・連想配列・未変換objectは型エラーです。原版の丸め・幅0・localeと異なる結果があります。

    例

    PRINT FORMAT("ab", 5)

    期待出力：

    ababa

    CHR

    文字コードから文字列を作成します。

    書式

    CHR(code)

    引数

    code
    数値または共通文法の数値文字列。0方向への切捨て後0〜0x10FFFF。

    戻り値・結果

    該当するUTF-16文字列。

    対応範囲と注意

    • 0〜0xFFFFは同じ値のUTF-16単位を1個、0x10000〜0x10FFFFは対応するペアを返します。NUL・サロゲート単独・非文字も生成できます。Unicode scalar限定の変換ではありません。
    • 先に0方向へ切り捨ててから範囲検査します。65.9はA、-0.5はNUL。原版の負値や範囲外のwrapは再現しません。
    • 数値文字列は前後空白・E/e指数を受理し、独自の長さ上限はありません。空文字列・空白だけ・16進表記・不完全指数・全角・桁区切り・NUL・非有限値は拒否します。
    • CHR($1F600)の数値リテラルは利用できます。文字列のCHR("$1F600")は拒否し、CHR("128512")なら同じ文字を返します。
    • 通常TRUE/FALSEは1/0、COM VT_BOOLは-1/0です。COM TRUEは範囲外、FALSEとEMPTYはNUL。NULL・NOTHING・ERROR・配列・連想配列・未変換objectは型エラーです。
    • 必須1/最大1引数で、個数・省略を式評価前に拒否します。OPTION SAMESTRやlocaleの影響はありません。孤立単位は出力時に置換されることがあり、表示と内部値を区別してください。

    例

    PRINT CHR(65)

    期待出力：

    A

    ASC

    先頭文字の文字コードを取得します。

    書式

    ASC(text)

    引数

    text
    対象文字列。

    戻り値・結果

    空文字列は0。先頭がサロゲートペアならUnicode scalar値、それ以外は先頭UTF-16コード単位。

    対応範囲と注意

    • 先頭2単位が有効なサロゲートペアならコードポイント、それ以外は先頭UTF-16単位を返します。孤立単位や非文字も数値として取得でき、常にUnicode scalarとは限りません。
    • 空文字列・EMPTY・先頭NULは0です。空とNULは戻り値だけでは区別できません。先頭空白を飛ばさず、後続文字や不正な単位の影響は受けません。
    • Stringは数値へ解析しません。ASC("$41")は$の36、ASC("NaN")はNの78です。数値入力のASC(65)は文字列65の先頭6の54を返します。
    • 数値はInvariantCulture G書式で文字列化します。通常TRUE/FALSEは1/0で49/48、COM VT_BOOLは-1/0で45/48。負の0は先頭-の45です。
    • NULL・NOTHING・ERROR・配列・連想配列・未変換object・非有限Numberは型/有限値エラーです。COM既定memberを暗黙に呼びません。
    • 必須1/最大1引数で、個数・省略を式評価前に拒否します。正規化・大小文字変換・書記素解析をせず、OPTION SAMESTRの影響も受けません。

    例

    PRINT ASC("A")

    期待出力：

    65

    ISUNICODE

    CP932で表現できない文字が含まれるかを調べます。

    書式

    ISUNICODE(text)

    引数

    text
    対象文字列。

    戻り値・結果

    厳密なCP932変換ができれば0、できなければ1。

    対応範囲と注意

    • 必須1引数です。引数の省略・過不足は評価前に拒否します。
    • 固定の厳密CP932を使います。髙・①等の拡張文字も含み、OSの既定コードページと文化設定、OPTION SAMESTRには依存しません。
    • 空文字列・EMPTYは0です。NULの後も調べ、補助平面文字や孤立サロゲート等の符号化不能な文字は1を返します。
    • ¥・‾・〜・−・¢・£・¬の近似変換や代替文字は許可しません。正規化も行いません。
    • 有限数値は文化設定に依存せず文字列化します。通常TRUE/FALSEは1/0、COM Booleanは-1/0で、判定結果はいずれも0です。文字列NaN/InfinityもASCIIとして0です。
    • 非有限Number、NULL・NOTHING・ERROR・配列・連想配列・objectは型エラーです。
    • ファイルの文字コードやフォント表示を判別する関数ではありません。原版の全Unicode・locale・Variant条件の一致は未確認です。
    • 戻り値は数値として1/0を保持する論理型です。VARTYPEで照会すると11、整数へ明示変換しても1/0になります。

    例

    PRINT ISUNICODE("ABC")

    期待出力：

    0

    TOKEN

    先頭のトークンを取り出し、元の変数へ残りを書き戻します。

    書式

    TOKEN(delimiters, source, [skipEmpty, quotes])

    引数

    delimiters
    区切りとして扱う文字の集合。有効なサロゲートペアは1文字です。
    source
    書き戻し可能な変数・配列要素・連想配列の単一キー。文字列または有限数値等を文字列化し、残余をStringまたはEMPTYで書き戻します。
    skipEmpty
    TRUEで連続区切りを飛ばします。既定FALSE。
    quotes
    TRUEで二重引用符の内側の区切りを無視します。既定FALSE。

    戻り値・結果

    切り出したString。区切り検出後の残余はString、区切りなしで終端まで取り出すとsourceはEMPTYです。

    対応範囲と注意

    • sourceには書き戻し先が必要です。添字や連想配列キーは一度だけ評価します。定数・関数戻り値・COMプロパティへの直接書戻しは拒否します。
    • quotesがTRUEなら二重引用符の内側を保護し、引用符自体も区切りません。引用符は残し、連続引用符も復号しません。閉じていない引用符以降は終端まで保護します。
    • 区切り文字列全体の一致で分割するSPLITとは異なります。文字ごとの完全一致を使い、OPTION SAMESTRやcultureで変更しません。NULも扱い、有効なサロゲートペアを分断しません。
    • 末尾の区切りで残余が空になる場合は空Stringです。区切りが見つからず終端まで取り出した場合はEMPTYです。返値は空でもStringです。
    • flagは有限数値を0方向へ切り捨て、非0ならTRUEです。数値文字列を扱い、Int32上限はありません。16進文字列・桁区切り・非有限値・不正型は拒否します。
    • 通常Booleanは1/0、COM Booleanは-1/0として文字列化します。NULL・NOTHING・配列・object等は文字列へ暗黙変換しません。
    • 必須2/最大4引数で、必須位置の省略や余分な引数は評価前に拒否します。任意位置の省略はFALSEです。引数の評価が既に起こした副作用は巻き戻しません。
    • Unicode区切り、参照の一回評価、巨大flag、Booleanや引用符自身の扱い等に原版との差があります。

    例

    DIM text = "a,b"
PRINT TOKEN(",", text)
PRINT text

    期待出力：

    a
b

    EVAL

    文字列を呼出元のscopeで式として評価します。

    書式

    EVAL(expression)

    引数

    expression
    評価する文字列を1個指定します。空文字・不正な式・非文字列はエラーです。

    戻り値・結果

    通常の式は評価値、:=による代入とTHREAD/CALL実行は空文字列を返します。

    対応範囲と注意

    • =は比較、:=は代入です。変数・配列・HASHTBL・COM memberを代入先にできます。
    • ユーザー関数と公開された通常の組み込み関数を呼べます。定数とEXPLICITの規則は通常の実行と共通です。
    • SPECIALCHARはEVALを記述したソースの設定、SAMESTRは実行設定を使用します。EVALの再帰は128段で制限し、取消を伝播します。
    • 単独の純粋式評価APIと初回コマンドライン版のプレビューでは呼び出せません。動的な式の解析エラーには外側の呼出し行を付けます。
    • 文字列のTHREADによるユーザー関数起動とCALLによるファイル実行にも対応します。THREADは空文字列を返し、終了コードやworker IDは返しません。動的CALLの初期化中の再入CALLは拒否します。
    • CALL先の初期化は同じ実行内で1回です。初期化失敗前に完了したPUBLIC更新や外部操作は戻さず、同じ実行内では失敗fileを再初期化しません。

    例

    a=2
b=4
c=0
EVAL("c:=3")
PRINT EVAL("INT(a*b+c-9.9/2)")

    期待出力：

    6
