    UWSC# ヘルプ / 画面・画像

    画面・画像

    色の取得、画像探索と保存の採用範囲を説明します。

    コマンドライン版とUWSC# アプリで実装のある範囲を説明します。角括弧内は省略可能です。機能全体の完成や原版互換を示すものではありません。

    PEEKCOLOR

    画面またはクリップボード画像の1画素の色を取得します。

    書式

    PEEKCOLOR(x, y, [colorMode, clipboard])

    引数

    x, y
    画面ではMOUSEORG設定を基準、クリップボードでは画像内座標。
    colorMode
    0（既定）はBGR、3はRGB、4は赤、5は緑、6は青。
    clipboard
    0（既定）は画面、0以外はクリップボード画像。

    戻り値・結果

    色または成分の数値。画像・画面の範囲外は-1。

    対応範囲と注意

    • 2～4引数です。座標は0方向へ整数に切り捨てます。colorModeの省略・EMPTYは0、clipboardの省略・EMPTYは0です。未定義の色指定と余分な引数はエラーです。
    • MOUSEORGを解除した画面取得は可視デスクトップ、設定中は選択した原点・FORE/BACKに従います。CLIENT/DIRECTではクライアント領域を使います。任意アプリや最小化・非表示時の描画内容は保証しません。
    • クリップボードでは画像左上が(0,0)です。MOUSEORGを無視します。標準DIBの1/4/8/16/24/32bit、色表・上下方向・RGB mask・RLE4/8と、OSの形式合成によるCF_BITMAP画像を扱います。
    • 有効な画像の範囲外は-1です。画像なし、クリップボード使用中、無効対象や取得失敗はEXCEPTで捕捉できる実行エラーです。取消は範囲外返値より優先します。
    • 画像は最大16777216ピクセル、クリップボードのコピーは最大134217728バイトです。埋込みICCの独自変換、JPEG/PNG圧縮DIB、独自PNG形式、混在DPIや全アプリの受入は対象外です。
    • 原版と異なり1bitの任意色表を保ち、clipboardの0以外を真とし、未定義の色指定を拒否します。原版との相違と未確認の停止条件は開発資料PEEKCOLOR-COMPLETION.mdを参照してください。

    CHKIMG

    画面から指定の画像を探し、結果座標を公開します。

    書式

    CHKIMG([image, mode, x1, y1, x2, y2, number, colorRange])

    引数

    image
    BMPのパス。拡張子なしは.bmpを補います。省略・空文字列・EMPTYはクリップボード画像。
    mode
    0は通常、1〜4は指定隅色の透過、-1は色関係による形状判定。既定0。
    x1, y1, x2, y2
    右下を含む探索矩形。空欄は取得元の端、EMPTYは0。MOUSEORGを基準とし、範囲へ切り詰めます。
    number
    既定1。正数は指定順、0とEMPTYも1。負数は全件を取得します。
    colorRange
    上位8bitが青、中位が緑、下位が赤の許容幅。既定0。IMG_MSK定数をORできます。

    戻り値・結果

    正番号は指定順が見つかれば1、なければ0。負番号は検出件数。G_IMG_X/Yは最後の検出座標、未検出は-999999。ALL_IMG_X/Yは負番号で全座標、正番号では空配列です。

    対応範囲と注意

    • 0～8引数です。通常一致、四隅色の透過、-1の色無視に対応します。未定義のmode・範囲外のcolorRange・引数過多や逆転/空範囲はエラーです。
    • 上から下、左から右へ探索し、一致後は横の重複をテンプレート幅だけ飛ばします。縦は1行ずつ進めます。指定順に足りなくても、途中の最後の検出座標を保ちます。
    • BMPはCORE/40/52/56/V4/V5ヘッダー、1/4/8/16/24/32bit、色表、RGB mask、RLE4/8、上下方向に対応します。プロファイルによる色変換やリンク先読込みは行わず、格納されたRGBで比較します。埋込みJPEG/PNGや未知の形式は拒否します。
    • 1×1の色無視は番号によらず成功1・座標0,0・空配列です。形状判定では色幅を無視し、RGBの同一/相違関係を使います。原版の8bit縮退変換は再現しません。
    • 実行開始時は座標-999999と空配列です。初回失敗後も読み取れます。失敗・取消時は直前の結果を保ち、正常終了時に更新します。取得中の取消は範囲エラーより優先します。
    • 画像は最大16777216ピクセル、一致は最大1000000件、DIB部分は最大134217728バイトです。ファイルは毎回読み直し、同じ更新時刻でも古いキャッシュを使いません。
    • MOUSEORGのFORE/BACKと原点に従います。CLIENT/DIRECTではクライアント領域を使います。空のクライアントは未検出0です。任意アプリや混在DPI、GPU/保護/最小化描画は一般保証しません。
    • 画像不在やclipboard使用中、分類済みの取得・形式・ファイルエラーはTRY/EXCEPTで処理できます。取消・メモリ不足・未知のbackend障害をすべて捕捉する仕様ではありません。原版との差と未確認条件はCHKIMG-COMPLETION.mdを参照してください。

    SAVEIMG

    指定した画面またはウィンドウの画像を、BMP・JPEG・クリップボードへ保存します。

    書式

    SAVEIMG([image, id, x, y, width, height, client, jpeg, captureMode])

    引数

    image
    保存パス。省略・空文字列・EMPTYはクリップボード。
    id
    0（既定）は仮想画面、それ以外は有効なウィンドウID。MOUSEORGとは独立。
    x, y
    画面は絶対物理座標、ウィンドウは選んだ原点からの物理座標。空欄は取得元の左上、EMPTYは0。
    width, height
    0（既定）は残りの範囲。負数・空範囲・取得元を越える範囲はエラー。
    client
    0（既定）は外枠、1はクライアント。その他はエラー。
    jpeg
    0（既定）は24bit BMP。-1/-4/-8/-16/-24/-32は各色深度のBMP。1～100はJPEG品質。
    captureMode
    0（既定）は遮蔽に応じた自動取得、IMG_FORE=1は画面、IMG_BACK=2は背景描画。id=0は常に画面。

    戻り値・結果

    戻り値はEMPTY。失敗は例外で通知されます。

    対応範囲と注意

    • 自動取得は、要求範囲が画面内で上位の可視ウィンドウに覆われていなければ画面、それ以外は背景を使います。FOREには覆うウィンドウも写り、BACKは画面外でも使えます。描画内容は対象アプリによります。
    • BMPは.bmp、JPEGは.jpg/.jpe/.jpegを大文字小文字を区別せず判定し、一致しない名前には.bmpまたは.jpgを末尾へ追加します。末尾のドットは除きます。JPEG指定のimage.bmpはimage.bmp.jpgとなります。
    • 画像名を省略した場合は非圧縮CF_DIBを公開します。負の品質は指定色深度、0と正のJPEG品質は24bitです。
    • 画像は最大16777216ピクセル。背景描画ではウィンドウ全体にも上限を適用します。ファイルは一時ファイル完成後に置き換え、置換前の失敗・取消では旧ファイルを保持します。
    • 原版の不正な16bitヘッダーや独自の減色を再現せず、標準BMPを使います。外枠はGetWindowRectを基準にします。原版差・設計案・未確認環境はSAVEIMG-COMPLETION.mdを参照してください。
    • 無効ID・範囲外・識別した保存/取得の操作失敗はTRY/EXCEPTで処理できます。取消・メモリ不足・未知のhost障害は一律に捕捉しません。同期描画/codec自体の強制中断は行いません。
